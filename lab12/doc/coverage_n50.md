# 커버리지와 N50 의 관계

## 1. 예상 (재조립 전에 작성)

- 커버리지 = 읽은 염기 총수 / 유전체 크기
  - 원본(trim) 읽기: R1 + R2 = 1,871,952 × 2 = 3,743,904 bp
  - 조립 길이(180,912 bp) 기준 약 20.7x, shovill 추정 유전체 크기(61,919 bp) 기준 약 60x
- 예상: 커버리지가 낮아지면 N50 이 작아진다.
  - 읽기가 적으면 어떤 위치는 아예 읽히지 않거나 겹침이 부족해 contig 가 이어지지 않는다.
  - 그러면 contig 가 더 잘게 끊기고(개수 증가), 긴 contig 가 줄어 N50 이 감소한다.
  - 절반(약 10x / 30x)으로 줄이면 원본 N50(58,878)보다 작아지고 contig 개수(12)는 늘 것이다.
  - 전체 조립 길이도 다소 줄어들 수 있다.

## 2. 방법

```
# 같은 seed(-s 11)로 R1·R2 를 뽑아야 짝이 맞는다
seqkit sample -p 0.5 -s 11 data/R1.trim.fastq -o data/R1.half.fastq
seqkit sample -p 0.5 -s 11 data/R2.trim.fastq -o data/R2.half.fastq

# 유전체 크기를 원래 조립과 같게 고정해서 조립
shovill --outdir doc/shovill_half_gsize_out --R1 data/R1.half.fastq --R2 data/R2.half.fastq --gsize 61919 --cpus 4
python3 src/n50.py doc/shovill_half_gsize_out/contigs.fa doc/contig_lengths_half.txt
```

- 뽑힌 읽기: 12,480 → 6,248 쌍 (50.1%), 937,152 bp × 2. R1/R2 읽기 이름 순서가 일치함을 확인함.
- 주의: 처음에 `--gsize` 없이 조립하자(doc/shovill_half_out) shovill 이 21-mer 빈도로 유전체 크기를
  4,551 bp 로 잘못 추정 → 깊이를 411x 로 오판 → 읽기를 다시 36.5% 로 줄여 SPAdes 가 실패했다.
  커버리지가 낮아지면 빈도 10 초과 k-mer 가 줄어 크기 추정이 깨진다. 그래서 원래 조립 값(61,919)으로 고정했다.

## 3. 결과

| | 원본 (trim) | 절반 |
|---|---|---|
| shovill 추정 깊이 | 60x | 30x |
| 조립 길이 기준 커버리지 | 20.7x | 10.4x |
| contig 개수 | 12 | 8 |
| 전체 길이 | 180,912 | 174,465 |
| 가장 긴 contig | 73,132 | 54,645 |
| **N50** | **58,878** | **54,544** |
| 가장 짧은 contig | 197 | 790 |

- 원본 길이: 73132 58878 35158 5981 3843 1046 816 790 645 223 203 197
- 절반 길이: 54645 54544 34937 15902 5981 4778 2888 790
- 절반 조립에서 커버리지 2x 미만 contig 1개(4,668 bp)가 제거됨.

## 4. 해석

- N50 은 예상대로 감소했다 (58,878 → 54,544, 약 7% 감소). 가장 긴 contig(73,132)가 사라지고 54,645 와 15,902 등으로
  끊긴 것으로 보여, 읽기가 부족한 구간에서 contig 가 이어지지 못했다는 예상과 맞는다.
- 전체 길이도 6,447 bp 줄었다. 일부 구간은 아예 조립되지 않거나 저커버리지로 걸러졌다.
- 예상과 다른 점: contig 개수는 늘지 않고 12 → 8 로 줄었다. 원본의 짧은 contig(197~645 bp, 반복 서열이나
  저커버리지 조각으로 보임)가 절반 데이터에서는 아예 만들어지지 않았기 때문이다. 즉 contig 개수만으로는
  조립 품질을 판단하기 어렵고, N50·전체 길이를 함께 봐야 한다.
- 30x(shovill 기준)도 여전히 조립 가능한 수준이라 N50 감소폭은 크지 않았다. 더 줄이면(예: -p 0.25) 감소가 더 뚜렷할 것이다.
